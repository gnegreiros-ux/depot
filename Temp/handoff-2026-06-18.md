## Décisions techniques à connaître

### Pattern icônes Lucide (établi dans cette session)
```css
/* CSS — seule approche fiable */
.ma-classe svg.lucide { width: Xpx; height: Xpx; }

/* Couleur sur fond sombre dans slide.white ou slide.light */
.slide.white svg.wico,
.slide.light svg.wico { color: #fff }
```
Ne jamais utiliser `style="width:..."` sur `<i data-lucide>` — ignoré par Lucide.

### Classes existantes

|---|---|---|
| `.cadre-ico` | 52px | Slide 8 — icônes principales |
