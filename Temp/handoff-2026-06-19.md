## Architecture technique à connaître

### Pattern icônes Lucide (CRITIQUE)
```css
/* Seule approche fiable — jamais style="width:..." sur <i data-lucide> */
.ma-classe svg.lucide { width: Xpx; height: Xpx; }

/* Icônes blanches sur slide.light / slide.white */
.slide.white svg.wico,
.slide.light svg.wico { color: #fff }
```

### Classes CSS établies
| Classe | Taille SVG | Usage |
|---|---|---|
| `.cadre-ico` | 52px | Slide 8 — icônes principales |
| `.card-ico` | 32px | Slides 19, 21 — icônes de cartes |
| `.agico` | 26px | Slide 17 — pastilles agents |
| `.gnode` | 36px | Slide 10 — cercles pipeline |
| `.wico` | couleur #fff | Icônes blanches sur fond sombre dans slide.light/white |

### Slides `.slide` — comportement overflow
- `.slide` : `position:absolute;inset:0;display:flex;flex-direction:column;justify-content:center;align-items:center;padding:4vw 6vw;`
- `#deck` : `overflow:hidden` — tout débordement est coupé des deux côtés
- Pour les slides denses : utiliser `justify-content:flex-start` + `padding-top:3.5vw` en inline style sur la `<section>`

### Variables CSS thème Agentica
```css
--brand: #0D9B8A        /* teal principal */
--brand-dark: #16201E   /* fond foncé */
--brand-deep: #0D1815   /* fond très foncé */
--brand-light: #5FE3D0  /* teal clair */
--accent: #ED6B86       /* rose accent */
--subtle: #E8EFED       /* fond neutre cartes */
--text: #111C1A         /* texte principal */
--muted: #384E48        /* texte secondaire */
```

### Types de slides
| Classe | Fond | Usage |
|---|---|---|
| `.dark` | brand-deep | Slides d'acte, architecture |
| `.navy` | brand-dark | Variante foncée |
| `.light` | #F2F5F4 | Slides intermédiaires |
| `.white` | #fff | Slides de données |

- Classe `.fu` + `data-d="1..5"` → délais d'entrée échelonnés
